# Data retention — ASSUMPTIONS unless legal signs off (PRD §61).

| Data | Rule |
|---|---|
| Active account data | Kept while ACTIVE/PAUSED |
| Deletion request | 14-day cooling-off, then irreversible delete |
| Safety holds (active reports, blocks) | Survive deletion; disclosed, minimal scope |
| Space evidence | 30 days after closure, moderators only |
| Messages of deleted users | Deleted except safety-hold excerpts |
| Verification data | Deleted with account except safety holds |
| Logs/audit | 90 days, safety access only (assumption) |

Deletion never bypasses an active hold. Other users are told the minimum.
