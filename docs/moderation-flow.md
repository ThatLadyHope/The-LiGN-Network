# Moderation flow (Phase 7, PRD §53–§54)

Report → Protect → Review → Action → Appeal

1. **Report** — from profile, conversation, voice/video, space, group, content.
   Never establishes guilt by itself.
2. **Protect** — immediate proportionate action: block, remove participant,
   end session, restrict communication, temp restriction, suspension.
   Serious threats: immediate protection, skip the queue.
3. **Review** — human review with evidence. Automated systems flag risk only;
   no permanent severe auto-penalties in ordinary cases.
4. **Action** — recorded against the safety record (apologies never erase it).
5. **Appeal** — false positives reviewable; appeals available where applicable.

Evidence: retained only as long as needed, access strictly limited.
Post-space reports accepted inside the 30-day window (see spaces module).
