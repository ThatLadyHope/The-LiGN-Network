# Safety response SLAs — ALL ASSUMPTIONS, need product + legal approval.

PRD §70 requires response-time measurement but sets no targets.

| Case | Assumed target |
|---|---|
| Credible threat / exploitation / serious violation | Immediate protection on report (< 1h), human review < 4h |
| Harassment / boundary violation | Review < 24h |
| Discomfort / incompatibility | No SLA; self-serve leave/pause |
| Appeals (false positives) | Decision < 7 days |
| Post-space reports | Accepted within 30-day evidence window |

Automated systems flag only; serious-threat protection never waits for review.
