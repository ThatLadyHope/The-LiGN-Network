# Safety categories (Phase 7, PRD §55)

| Category | Example | Intervention level |
|---|---|---|
| ordinary-incompatibility | Not a good fit | None — leave/pause offered, no record |
| discomfort | Something feels off | Clarify/boundary/pause/leave/report offered |
| boundary-violation | Repeated post-refusal requests | Warning, communication restriction |
| harassment | Targeted unwanted contact | Block, temp restriction, review |
| serious-violation | Hate, sexual coercion | Immediate protection + human review |
| credible-threat | Threat of harm | Immediate protection + suspension + authorities path |
| exploitation | Grooming, scams, minors at risk | Immediate protection + suspension + preservation |
| other-high-risk | Anything else dangerous | Immediate protection + human review |

Auto-detection flags only — never permanent severe penalties in ordinary
cases without human review. Serious threats skip the queue.
